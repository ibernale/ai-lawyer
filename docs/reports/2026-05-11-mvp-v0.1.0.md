## Metric definitions

| Metric | Formula | Weight |
|--------|---------|--------|
| citation_recall | items_found / items_expected (must_cite_any_of) | 0.35 |
| citation_precision | claims_passed / claims_total | 0.25 |
| hallucination_free | 1 − (broken_refs + uncited_claims) / (claims_total + 1) | 0.20 |
| concept_coverage | concepts_found / concepts_expected | 0.10 |
| forbidden_claim_free | 1 − forbidden_claims_found / total_forbidden | 0.05 |
| caveat_coverage | caveats_mentioned / caveats_expected | 0.05 |

`legal_quality_score` = weighted average of above (weights from `evals/config/weights.yaml`).
