# packages/rag

Contextual retrieval pipeline for lex-agents. Implements hybrid search (dense

- sparse) over Qdrant using BAAI/bge-m3 embeddings, followed by BAAI/bge-
  reranker-v2-m3 reranking. Applies the Anthropic Contextual Retrieval technique:
  each chunk is enriched with a situational context paragraph generated by
  claude-haiku-4-5 with prompt caching of the parent document. See ADR 0003.
