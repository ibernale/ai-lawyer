## Golden dataset schema (YAML)

```yaml
# evals/golden_dataset/<domain>/<id>.yaml
id: "reg-banca-001"
domain: "regulatorio_bancario_ue_es"
difficulty: "medium"          # easy | medium | hard
query: "¿Cuál es el requisito mínimo de fondos propios bajo CRR2?"
expert_reviewed: false         # true only after human legal review
created_at: "2025-10-01"

must_cite_any_of:
  - source_id: "32013R0575"   # CELEX for CRR
    article: "92"
  - source_id: "32019R0876"   # CRR2 amendment
    article: "1.5"

must_contain_concepts:
  - "capital de nivel 1 ordinario"
  - "activos ponderados por riesgo"

forbidden_claims:
  - "el requisito es del 8%"   # common hallucination

must_have_caveat: true
difficulty_rationale: |
  Requires distinguishing CRR original from CRR2 amendment and stating which
  percentage applies at which date.
```

## Metrics

| Metric | Definition |
|--------|-----------|
| `citation_recall` | % of `must_cite_any_of` items covered in response |
| `citation_precision` | % of `[REF:n]` that pass verifier |
| `hallucination_rate` | % of claims flagged as unsupported by verifier |
| `concept_coverage` | % of `must_contain_concepts` present in response |
| `forbidden_claim_rate` | % of `forbidden_claims` that appear in response |
| `caveat_coverage` | 1.0 if caveat present when `must_have_caveat=true` |
| `routing_accuracy` | correct domain routed / total (for router agent) |
| `latency_p50` | median end-to-end latency (ms) |
| `latency_p95` | 95th percentile latency (ms) |
| `cost_per_query` | Anthropic API cost in USD |

## Legal quality score

```python
legal_quality_score = (
    0.35 * citation_recall +
    0.25 * citation_precision +
    0.20 * (1 - hallucination_rate) +
    0.10 * concept_coverage +
    0.05 * (1 - forbidden_claim_rate) +
    0.05 * caveat_coverage
)
```

Weights are configurable via `evals/config.yaml`. Default shown above.

## Run modes

| Command | Cases | When |
|---------|-------|------|
| `make eval-quick` | Smoke set (≤5 cases, one per difficulty) | Every PR |
| `make eval` | Full dataset | Nightly CI, release |

Smoke set: pick the first case of each difficulty level from each domain.

## CI quality gate

- PR that regresses `legal_quality_score` by more than 5% vs. `main` baseline → CI red
- Baseline stored at `evals/reports/baseline.json` (gitignored; fetched from
  CI artifact store)
- Any case generated by Claude without human review has `expert_reviewed: false`
  and is excluded from the official quality score; it contributes only to the
  `hallucination_rate` and `forbidden_claim_rate` smoke checks.

## Report output

Reports written to `evals/reports/<timestamp>_<run_id>.json` (gitignored).
Format:

```json
{
  "run_id": "abc123",
  "timestamp": "2025-10-01T14:00:00Z",
  "commit": "a1b2c3d",
  "scores": { "legal_quality_score": 0.87, "..." },
  "cases": [{ "id": "reg-banca-001", "passed": true, "..." }]
}
```
