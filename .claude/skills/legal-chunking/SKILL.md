## Atomic chunk units

Chunk at the lowest *complete* logical unit available in the document:

| Document type | Atomic unit |
|---------------|-------------|
| BOE — Ley / Real Decreto | Artículo completo |
| BOE — Ley (artículo largo) | Apartado, preserving article context in metadata |
| EUR-Lex — Reglamento/Directiva | Artículo completo |
| EUR-Lex — Preámbulo | Considerando individual |
| Sentencia (CENDOJ, future) | Fundamento de Derecho; Fallo as separate chunk |
| Circular BdE | Norma (equivalente a artículo) |

**Never cut mid-sentence.** If an article must be split by token budget,
split at apartado boundaries and carry `parent_article` in metadata.

## Metadata schema (every chunk must carry all fields)

```python
class ChunkMetadata(BaseModel):
    chunk_id: str            # stable hash: sha256(source_id + hierarchy_path)
    jurisdiction: str        # "ES" | "EU"
    source: str              # "BOE" | "EURLEX" | "BDESPAIN"
    source_id: str           # ELI URI, CELEX number, or BOE document ID
    document_type: str       # "reglamento" | "directiva" | "ley" | "real_decreto" | ...
    hierarchy_path: str      # "CRR > Título II > Capítulo 2 > Sección 3 > art. 92 > apt. 1"
    article_number: str | None
    section_type: str        # "articulo" | "apartado" | "considerando" | "fallo" | ...
    language: str            # "es" | "en" | "fr"
    publication_date: date
    entry_into_force: date | None
    in_force_at_indexing: bool
    checksum: str            # sha256 of raw text content
    contextual_summary: str  # generated by Contextual Retrieval step
```

## Contextual Retrieval enrichment

After chunking, generate a situational context paragraph for each chunk:
- Use `claude-haiku-4-5` with **prompt caching** of the parent document
  (cache the full document text in a system/user message with cache_control)
- Context paragraph: 50–100 words, answers "where does this chunk sit in the
  full document and what is its purpose?"
- Store as `contextual_summary`; index `chunk_text + "\n\n" + contextual_summary`

```python
# Pseudocode
context = haiku_client.generate(
    system=[{"type": "text", "text": full_document_text,
             "cache_control": {"type": "ephemeral"}}],
    prompt=CONTEXT_GENERATION_PROMPT.format(chunk=chunk_text),
)
chunk.contextual_summary = context
```

## Token budget

| Embedder | Max tokens |
|----------|-----------|
| BAAI/bge-m3 | 8192 tokens |

Target chunk size: 512–1024 tokens. Never exceed 2048.
If an article exceeds 2048 tokens after splitting by apartado, log a warning
and create a `TRUNCATED` flag in metadata.

## Reproducibility

Chunking must be deterministic: same input → same `chunk_id`. Use
`sha256(source_id + "::" + hierarchy_path)` as the stable ID. Do not use
UUIDs or timestamps in chunk IDs.
